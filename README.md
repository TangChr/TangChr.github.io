# [seaweed.dk](http://seaweed.dk)

Social "Hub" build on [Jekyll](http://jekyllrb.com) and hosted on [GitHub Pages](https://pages.github.com).

### Run in Docker
```bash
docker compose run --rm jekyll bundle install
docker compose up
```
